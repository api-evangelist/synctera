Synctera is a Banking-as-a-Service platform connecting fintechs to a network of sponsor banks. Provides REST APIs for personal/business customers, accounts, cards, internal transfers, payment schedules, ACH payments, mRDC, KYC/KYB verification, document verification, and disclosures.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/synctera/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/synctera/refs/heads/main/apis.yml)

## APIs

### Synctera Platform API

REST API covering Customers (Personal & Business), Accounts, Cards, Internal Transfers, Payment Schedules, ACH Payments, mRDC, KYC/KYB Verification, Document Verification, and Disclosures. Authenticated via API keys issued from the Synctera Console.

- **Human URL:** [https://docs.synctera.com/api-reference](https://docs.synctera.com/api-reference)
- **Base URL:** `https://api.synctera.com`
